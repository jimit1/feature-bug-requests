# Feature / Bug Requests

Momentive Software take-home, the simple version. A prioritized digest for the product team, built from Gong calls and Salesforce cases.

- `deck/deck.html`  the presentation, animated. Open in a browser, arrow keys to move, F for fullscreen.
- `deck/Feature-Bug-Requests.pptx`  the same seven slides, static, for forwarding.
- `deck/build_pptx.js`  rebuilds the pptx from `deck/png/body/*.png` (rendered from deck.html in `?static=1&body=1` mode).

Build instructions for the prototype are in `BUILD.md`. This README gets replaced by the one BUILD.md section 7 describes once the prototype exists.
