Appendix: the decisions behind it

Code

  • Python 3.12, one pipeline file (367 lines)
  • one ask file (48), one Lambda (45)
  • one HTML page, no framework (693)
  • 10 tests, a golden set, git is the database

Models, by tier

  • readers: Haiku 4.5, cheap tier
  • editor: Opus 5, frontier tier
  • ask: Sonnet 5, fast tier
  • named in one config file, never in code

Mock data, real API shapes

  • 30 Gong calls, 1,407 turns, 16 hours
  • 23 Salesforce cases, 95 comments
  • 9 accounts: 6 customers, 3 prospects
  • decoys: a prospect, one issue in two voices, internal notes

Verification, in code

  • a quote must match the cited turn exactly
  • rejected with a reason, never patched
  • repeated quotes dropped, one theme per ask
  • agents answer only through a schema; a golden set runs nightly to catch drift

Hosting

  • page: GitHub Pages
  • nightly job: GitHub Actions, one cron line
  • ask: one AWS Lambda, passphrase, daily cap
  • Bedrock is the swap when data must stay in the account; the model call is one function

First week, API path

  • $0.05 per night average, $0.10 busiest
  • 22 claims verified, 2 rejected, 10 themes
  • 10 of 12 later claims joined an existing theme
  • every run is a commit with tokens and cost
